## 已明确的产品主线

- 手机是基础入口，不要求购买语音盒、药盒或其他专用设备。
- 后端全双工语音对话与 Agent Loop 并行：自然交流不中断为设计目标，Agent 在后台整理信息、维护记忆、创建受控的定时任务与关怀事项。
- “全局记忆”指按用户隔离、跨会话使用的个人长期记忆，不是全体用户共用的档案，也不自动向子女开放。
- 老人既有交流和分享的需要，也有记事与生活安排需要。普通闲聊本身有价值，不要求每次产生任务。
- 子女端帮助理解父母生活、延续交流、表达真实关心；只有明确求助才需要事项跟进。
- 自建或其他品牌的人体存在传感器、智能开关等是可选数据源；药盒、语音盒不是必备项。具体接口、型号、权限与能力逐项核实。
- 可靠保存、正确理解、适当共享是三个不同要求。持久化成功不证明模型理解正确，保存成功也不产生家属访问权。

## 状态与证据

上述主线来自用户明确澄清；子女端“最近的生活／下次聊什么／需要你参与”、原话片段与双向留言是本轮形成的设计方案，仍需原型和家庭试用验证。

“部分老人期待长时间交流、会连续发送长语音”来自讨论中的观察，不是总体统计，也不把老人的表达视为需要清除的噪声。本文没有真实用户研究结果、已实现功能或效果数字。

历史的“硬件必交付、按键语音优先、子女待办中心”等口径已被本轮产品主线替代。变更追溯见 [风险与决策](../ideas/12-风险与待验证.md)；历史 Git 版本与 `ideas/archive/` 不作为当前实施指令。
