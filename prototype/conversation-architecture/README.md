# AgeGuard · 老人、AI 助理、Agent 与家属的动态架构

打开 **[`../conversation-architecture.html`](../conversation-architecture.html)**，即可查看独立、可离线打开的单文件架构动画。无需服务器、账号、麦克风或模型密钥。对应的完整情景见 [对话演示](../conversation-demo.html) 与 [逐字稿](../conversation-demo/script.md)。

**证据等级：架构设计与虚构情景动画。不是正在运行的调用追踪，不证明真实全双工、Agent 并行、持久化、授权或消息送达已经实现。** 章节按处理机制组织，不是对话发生时间的严格重放。台词在构建时直接引用原有养鱼情景，附会话与轮次来源。

## 四个主角色

| 角色 | 负责什么 | 不应做什么 |
|---|---|---|
| 老人 · 陈阿姨 | 用手机聊天、补充、改口，决定个人安排与分享范围 | 不必先绑定家属或购买专用硬件 |
| AI 助理 · 小安 | 实时倾听、回应、澄清和统一播报；内部包含输出协调 | 不绕过业务服务写记忆／建任务，不提前宣布成功 |
| 后台 Agent | 根据最终轮次与修订事件，检索背景、整理候选、有界调用工具 | 不用提示词代替权限，不把闲聊一律任务化，不无限轮询 |
| 家属 · 小林 | 了解获准近况、准备交流、本人留言、接手具体求助 | 不直接访问妈妈私人记忆，不由 AI 冒充她回应 |

这是**逻辑职责划分，不强制部署两个不同模型**。图中其余模块是信息流必须经过的业务职责，也不强制使用某款队列、数据库或厂商 SDK。

## 图里的信息怎样走

1. **交流与后台整理分流**：老人 ↔ AI 助理；最终转写、来源与修订事件异步流向后台 Agent。
2. **记忆获取**：Agent → 业务网关校验读权限 → 个人长期记忆 → 命中记录与来源 → Agent → AI 助理。
3. **记忆新增／修订**：候选经来源、保留设置和版本校验后写入。M04 为新增近况，M03 从小颗粒修订为薄片；旧版不再作为当前事实。
4. **个人提醒**：九点改十点使旧草稿失效；确认绑定当前版本，成功保存才生效，到时由确定性调度程序执行，而不是模型持续看时间。
5. **家庭内容分成两条**：经许可形成近况与话题的授权投影；明确求助另外创建请求，只有后者需要接手与办结。
6. **家属读取**：家属入口只读取授权投影、收到的明确请求和本人留言，不检索老人的全量个人记忆。
7. **本人回应与回流**：小林操作 → 家属入口 → 网关 → 独立业务记录；带来源结果经 Agent、AI 助理统一转达老人。已接手、家属自报完成与老人确认收到分开。

“明确求助与本人留言”在图中合并为一个家庭协作模块，但**仍是分立记录与状态**，不是把留言当工单评论。拒绝一次生活分享也不会禁止小林以后另行发送获准的本人留言。

## 怎样看动画

- 默认按 **9 章 × 每章 9 秒**自动循环，可选 6／12 秒。
- 高亮连线与流动点表示当前路径；暗线保留全局上下文。流动点从来源沿路径移动到箭头端。
- “自动讲解”控制章节切换；“流动动画”独立控制 CSS 流动和 SVG 移动点。
- 可点章节、上一章／下一章，或切“架构总览”同时看全部 18 条路径。
- 另有“拒绝分享”“保存失败”两条边界路径。前者不点亮投影出口；后者不点亮提醒保存出口，避免把失败表现成已经生效。
- 下方分别说明**输入是什么、怎样处理、产生什么**，以及当前不能越过的边界；展示业务事件与数据，不展示或编造模型内部思维。
- 支持缩放、全屏、深浅主题。小屏在图内横向滚动，不将整张架构压缩成不可读的小字。
- 空格切换自动讲解，方向键翻章；`T` 切主题，`E` 导出。焦点在表单、按钮、菜单时不抢占播放器按键。
- 尊重系统“减少动态效果”：默认关闭自动讲解与流动，可手动开启；页面进入后台时关闭二者。

## 导出

原有 Archify 主题、工具栏和脚本保持不变。导出前自动暂停章节切换，固定当前高亮和图内标题；建议先选择“架构总览”再导出完整图。

- PNG / JPEG / WebP：原生高分辨率栅格化。此图 1520×950，4× 超过模板 16Mpx 限制，自动选择 3×（4560×2850）。
- SVG：包含深浅双主题、当前章节状态、来源短句和向前流动的点。
- GIF / WebM：只录**当前图的连接流动**，不录全部分章说明，也不含语音。完整讲解请录屏。
- GIF 建议先用 1× / 10fps / 2秒；高倍率、长时长会显著增加内存。剪贴板、编码器与 Canvas 支持受浏览器和设备条件影响。

### WebM 的额外修复与证据

本次验证中，原模板的 VP9／首帧绘制前启动采集路径虽然产生 WebM 文件，**解码后却是全黑**。文件非空不能算导出成功，这属于导出正确性问题，不应归咎为“用户网络不好”。

因此仅在此页面新增 `video-export.js`：保留原模板和原脚本，独立处理 WebM 菜单与接口，优先使用浏览器支持的 VP8，逐帧绘制后显式请求采集，并停止与释放媒体轨道。若没有相应 API 或编码器，明确报错并建议 GIF／录屏，不假称成功。当前 Chrome 输出已经实际解码，检查两处时刻的帧非黑且像素发生变化；不据此保证所有浏览器和设备。

没有新增外部 SDK、CDN 脚本或网络请求。原模板的 Google Fonts 为可选异步字体，断网退回系统字体。

## 源码与构建

```bash
node prototype/conversation-architecture/build.mjs
node prototype/conversation-architecture/verify.mjs
```

构建调用技能的 architecture renderer（子进程 **15 秒超时**），执行 JSON Schema 和布局校验，然后以附加样式与脚本添加讲解。若技能缺少 ajv，会告警并仅执行布局检查；本次使用已安装 ajv 的完整校验。

| 文件 | 作用 |
|---|---|
| `system.architecture.json` | 11 个组件、4 个主角色、18 条连接、业务边界及图例卡片 |
| `story.mjs` | 9 章主线、2 条边界、信息处理说明与原情景台词引用 |
| `animate.css` / `animate.js` | 高亮、流动控制、章节轮播、缩放、全屏与减少动态效果 |
| `video-export.js` | 附加的 WebM 显式逐帧采集，不修改原始导出脚本 |
| `build.mjs` | 自动生成单文件 HTML；修正图例边距并补充图例遮罩，不修改技能 renderer |
| `verify.mjs` | 静态结构、浏览器交互与真实导出／视频解码检查 |

可选浏览器检查沿用前一演示的临时 Playwright 安装，不引入产品依赖：

```bash
PLAYWRIGHT_MODULE=/tmp/ageguard-demo-tools/node_modules/playwright/index.mjs \
  node prototype/conversation-architecture/verify.mjs --browser
PLAYWRIGHT_MODULE=/tmp/ageguard-demo-tools/node_modules/playwright/index.mjs \
  node prototype/conversation-architecture/verify.mjs --exports
```

需要另行安装时可执行：

```bash
npm install --prefix /tmp/ageguard-demo-tools playwright --ignore-scripts --no-audit --no-fund --fetch-retries=0 --fetch-timeout=15000
```

默认浏览器为本机 Google Chrome，可用 `CHROME_BINARY` 指定可执行文件。浏览器启动 10 秒、普通动作 5 秒、导航 10 秒、下载 15 秒超时；附加视频帧加载和编码结束各限制 10 秒。命令调用方另设 15–30 秒的总时限。证据输出到系统临时目录 `ageguard-architecture-validation/`，可用 `DEMO_CHECK_OUTPUT` 更改。

## 本次验证范围

- 静态校验：嵌入脚本语法、原主题／工具栏／脚本完整保留、无运行时外部脚本、节点与边绑定、隐私路径、箭头方向、组件及图例的双矩形遮罩和 z-order。
- Chrome `file://` 且外部网络阻断：全部 11 章节、高亮边数、文字不裁切／不溢出节点、总览、暂停流动、全屏、缩放、390px 小屏滚动、减少动态效果与自动翻章。
- 实际生成 SVG、PNG、JPEG、WebP、GIF 与 WebM；WebM **额外解码检查非黑帧与帧变化**，而非只检查文件头。动画导出测试为 1× / 10fps / 2秒。
- 未验证跨浏览器／设备、剪贴板授权，以及任何真实语音、模型、数据库、调度、消息送达或家庭体验。架构动画不能替代这些能力的验收。
