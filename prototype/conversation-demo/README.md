# AgeGuard · 把生活接着聊

三视角、可逐句播放的虚构对话演示。入口为 **[`../conversation-demo.html`](../conversation-demo.html)**，可以直接双击打开，不需要服务器、账号或密钥。单文件已包含脚本、样式、SVG 和 GIF 编码器；复制该 HTML 即可演示。

配套的 **[四角色动态架构图](../conversation-architecture.html)** 将同一情景拆解为老人、AI 助理、后台 Agent 与家属之间的信息路径，展示个人记忆、业务校验、授权投影与反馈回流。

**证据等级：情景模拟 / 本地确定性状态回放。不是已接通的语音产品，也不是真实用户研究。** 不采集麦克风、不调用线上模型、不保存业务数据、不发送消息、不访问微信或外部电话。只有主题选择会由 Archify 尝试保存在 localStorage；刷新会重置故事状态。

## 怎么演

1. 选择“完整故事”，点击“播放演示”。静音时间轴约五分钟，共 42 步。
2. 左侧看老人听到的对话；中央看模拟最终转写、记忆检索、候选、网关与版本；右侧看家属**获准可见**的内容。三栏是讲解者视角，不表示老人和家属可以查看后台隐私。
3. 可以暂停、调速、逐步、拖动进度，或按章节跳转。最新新增／修订记忆显示在最上方，修订项展示旧版与当前版。
4. 可选“系统朗读”。只有可用中文系统语音才出声，**不是父母原始录音，也不克隆任何人声音**。系统音色、联网依赖因设备而异，可能无法区分多个音色；失败、无中文音色或最长 30 秒未结束时切回字幕。暂停、跳转停止朗读，继续会重读当前句。较长句会等待朗读，实际时长可能超过五分钟。
5. 选择“如果她不想分享”或“如果保存失败”，从分叉比较点查看。共有前置状态由**该分支自己的脚本**重建，不继承其他分支的结果；“从头回放”则回到该分支开头。
6. 家属卡片中的“演示接手／反馈”按钮只是跳转剧本、重建对应状态，不是真实家属操作。
7. 页面底部有逐字脚本（可下载当前分支 Markdown）与可展开的 dynamic-archify 时序图。

快捷键：空格播放／暂停、左右方向键逐步、`T` 切主题、`E` 导出图。焦点在表单、按钮、菜单中时，播放器不抢占按键。切到后台标签页自动暂停。小屏改为纵向排列；可用全屏模式减少顶部介绍。系统“减少动态效果”偏好会停止装饰性 CSS / SVG 流动。

## 故事与演示定位

人物、日期、台词全为虚构。时间为 2026-10-23（周五）至 10-25（周日），时区 Asia/Shanghai。

| 锚点 | 展示 | 关键边界 |
|---|---|---|
| A00—A04 | 晚间聊养鱼；读 M01/M02，新增 M04 | 原话有来源；个人记忆不默认共享；提交成功才说记下 |
| A05—A11 | 九点改十点；一次换水提醒 | 旧候选失效；确认不等于已保存；不推导周期安排 |
| A12—A15 | 授权鱼近况和回忆 | 接收人仅小林；不发整段聊天或个人提醒 |
| A16—A19 | 请小林带鱼粮 | 明确求助才进入跟进；规格未知先核对 |
| B00—B07 | 新会话召回；小颗粒改薄片 | 清空工作上下文；记忆 v1→v2；更新共享请求另行确认 |
| B08—B10 | 模拟十点提醒与本人反馈 | 模拟时钟／终端展示；本人自报不等于客观核验 |
| F00—F03 | 小林回顾话题、留言并接手 | 家属只取授权投影；不把问候当工单；不冒充本人留言 |
| C00—C04 | 转达留言；家属反馈；老人确认收到 | 已提交／已转达／已接手／反馈／本人确认彼此区分 |
| P01—P03 | 拒绝分享 | 普通家属空态；不留“有一条不愿分享的内容”等暗示 |
| X01—X03 | 保存失败、恢复、重复提交 | 失败没有提醒；同一幂等标识恢复只创建一个实例 |

初始记忆是显式的虚构夹具 S-00/T-02，不是模型“天然记得”。本人的普通生活记忆保留与小林文字留言接收设置在开场说明；分享和求助逐次确认。演示没有覆盖完整删除／备份／撤权恢复实现，也不应据此声称这些能力已经完成。

## 三类输出不能混淆

- **生活近况／关怀线索**：妈妈愿意分享的鱼近况和回忆，帮助“下次聊什么”。不诊断情绪，不要求办结，不生成孝心分数。
- **个人安排**：周六十点的单次换水提醒，仅老人可见。提醒用专门对象，记忆摘要不能改写计划。
- **家属待办**：明确请求带鱼粮，独立的确认、授权、版本和状态。等待回应 → 接手 → 家属自报完成 → 老人确认收到。

`familyView()` 用字段白名单输出授权内容，来源仅输出引用而非完整内部原话，防止候选问题中的未共享附带信息流出。它只是本地说明与测试结构，**不构成真实鉴权或安全边界**；整个 HTML 含所有虚构剧本，不能用于存放真实隐私。

## 图像与动画导出

保留 Archify 原有主题、工具栏、导出脚本及内嵌 gif.js。右上角 Export 导出的对象是**底部时序图**，不是整个三栏演示：

- PNG / JPEG / WebP，默认最高 4×，大图按模板 canvas 限制降级；SVG 包含双主题。
- GIF / WebM 仅导出连接线与流动点的动画，**没有语音，也不包含对话播放过程**。整段演示请录屏。
- 剪贴板、MediaRecorder 编码格式、大画布与 GIF 内存受浏览器和系统条件限制。GIF 建议先用 1×、10fps、2秒试导出。
- 字体的 Google Fonts 链接是模板原有可选异步加载；断网时退回系统字体。系统语音是否可离线要看设备提供的音色，不能保证。

## 修改与构建

不要直接编辑生成的 HTML 或 `script.md`，修改源文件后重建：

```bash
# 仅构建时用到 Node；使用生成页不需要 Node。
node prototype/conversation-demo/build.mjs
node --test prototype/conversation-demo/scenario.test.mjs
```

构建器调用技能的 sequence renderer，子进程显式限制 **15 秒**。它先做 JSON Schema / 布局校验，再添加播放器；不修改 renderer、原始主题变量、工具栏或已有脚本。若 ajv 未安装，renderer 会告警并只执行布局检查；要启用 schema 校验：

```bash
npm ci --prefix .agents/skills/dynamic-archify --ignore-scripts --no-audit --no-fund --fetch-retries=0 --fetch-timeout=15000
```

| 文件 | 作用 |
|---|---|
| `scenario.mjs` | 唯一剧本源；三个情景、来源、操作、隔离后的家属投影与确定性回放 |
| `player.html` / `player.css` / `player.js` | 播放器、三栏界面、朗读降级与交互 |
| `flow.sequence.json` | 符合 Archify schema 的时序图源 |
| `build.mjs` | 受限时构建；生成单 HTML 和逐字脚本 |
| `script.md` | 自动生成的完整讲解稿，含全部分支、来源与事件字段 |
| `scenario.test.mjs` | 无依赖 Node 测试，含隔离、状态、不提前成功及 SVG / 模板约束 |
| `browser-check.mjs` | 可选 Playwright 浏览器检查，不是产品能力验收 |

可选浏览器检查（测试依赖可安装到临时目录，不引入产品 SDK）：

```bash
npm install --prefix /tmp/ageguard-demo-tools playwright --ignore-scripts --no-audit --no-fund --fetch-retries=0 --fetch-timeout=15000
PLAYWRIGHT_MODULE=/tmp/ageguard-demo-tools/node_modules/playwright/index.mjs \
  node prototype/conversation-demo/browser-check.mjs
PLAYWRIGHT_MODULE=/tmp/ageguard-demo-tools/node_modules/playwright/index.mjs \
  node prototype/conversation-demo/browser-check.mjs --exports
```

默认使用本机 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`；其他平台通过 `CHROME_BINARY` 指定 Chromium 路径。浏览器启动限制 10 秒、普通动作 5 秒、导航 10 秒、导出下载最长 15 秒。测试产物默认在系统临时目录的 `ageguard-demo-validation/`，可通过 `DEMO_CHECK_OUTPUT` 更改。执行命令还应由调用方设置合理的总时限（本次各命令 15–30 秒），不做整个用户目录的递归探测。

## 本次已验证与未验证

- 已通过 13 项 Node 测试：全部快照重放、候选与确认、改口失效、个人记忆修订、共享单独确认、家属字段白名单、分支隔离、失败与幂等、两类事项状态、留言来源、内嵌 JS 语法及 SVG 遮罩／层级、原始 Archify CSS / 工具栏 / 脚本保留。
- 已在本机 Chrome 的 `file://`、外部网络请求阻断下检查每个情景的每一步，测试播放／暂停／跳转／重置、家属操作按钮、主题持久化、全屏、桌面与 390px 移动布局及脚本下载。
- 中文音色为空、语音报错、语音挂起的降级用 **mock 浏览器语音 API + 虚拟时钟** 验证；不冒充真实中文音色听感或真实语音链路测试。
- 已实际生成 SVG、PNG（3280×4640）、JPEG、WebP、GIF 和 WebM 导出文件；动画测试为 1× / 10fps / 2秒，只代表本机 Chrome 的图表导出。
- 未验证其他浏览器／设备、剪贴板授权、真实 ASR／模型／音色听感、全双工、云端持久化／崩溃恢复、真实消息送达及实际家庭体验。演示检查通过不能替代这些验收。
