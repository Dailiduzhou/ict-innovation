# 01 · 定位与边界

## 一、核心定位

> **AgeGuard 是能自然交流、记住个人生活并主动提供帮助的老人语音生活助理；在老人授权下，帮助子女理解父母、延续交流和参与具体帮助。**

完整产品依据：[用户](../product/01-用户.md)、[需求](../product/02-需求.md)、[讲故事](../product/03-讲故事.md)。

手机即可使用。核心不是两个盒子、纯陪聊、健康报表或家庭工单，而是**交流的连续性＋重要信息的可靠记忆＋受控行动＋真实家庭连接**。

## 二、要解决的矛盾

在讨论所观察的部分家庭里，老人期待交流、愿意讲生活细节，子女却未必有时间逐条听完长语音。这里既有信息处理负担，也有维持亲密关系的需要，不能只做摘要压缩。

| 需求 | 产品回应 | 不能混淆 |
|---|---|---|
| 有人愿意听 | 自然、可打断的语音交流 | 闲聊不必产生任务 |
| 重要的事以后仍有用 | 按用户隔离的长期记忆与可靠存储 | 存储成功不等于理解正确 |
| 不想逐项设置工具 | 从意愿提出提醒，确认或有效预授权后执行 | 习惯不自动变成计划 |
| 家人想知道最近怎样 | 获授权近况、原话和联系前回顾 | 不默认展示私人记忆 |
| 有具体事情需要协助 | 接收人明确的请求与反馈 | 分享、联系邀请不全是工单 |

核心价值不是让子女少与父母交流，而是少整理碎片信息、少重复交代，更容易接着聊。

## 三、竞争参照：不把现有市场说成空白

以下来自讨论中的官方产品／帮助资料核对，未作本项目上手对照；能力存在不等于对方开放 SDK 或在国内同等可用。

| 参照 | 已介绍的能力 | 本项目真正需验证的差别 |
|---|---|---|
| 微信／电话＋提醒工具 | 熟人交流与另行安排提醒 | 是否减少整理负担，同时不损害真实联系 |
| 小度智能屏 | 语音、亲情通话、远程设置提醒 | 不将“老人语音入口”说成独创 |
| ElliQ＋家属应用 | 陪伴、提醒、家庭消息与连接 | 个人记忆和家庭上下文是否更合适 |
| Medisafe | 用药记录与亲属协助 | 不将“用药提醒＋家属”说成市场空白 |
| Hero | 自动分药、提醒与家属协作 | 不与专用设备争未具备的给药能力 |
| Caring Village | 共享任务、责任人、照护计划、角色权限 | 不将“有人接手、有状态”作为唯一创新 |
| 华为家庭空间 | 经授权健康共享与部分健康提醒 | 日常生活语境、真实交流而非健康看板 |

来源：[小度](https://anquan.baidu.com/article/1783)、[ElliQ](https://elliq.com/pages/caregivers)、[Medisafe](https://help-center.medisafe.com/en/articles/11793638-caregiver-guide-how-to-use-medisafe-to-manage-a-family-member-s-medications)、[Hero](https://herohealth.com/medication-management/)、[Caring Village](https://caringvillage.com/app/)、[华为家庭空间](https://consumer.huawei.com/cn/support/content/zh-cn15903791/)。

主张应是特定人群中的组合与交互价值，而非“别人只聊天不办事”“隐私只有我们重视”。壁垒也不能由模型 API 数量或架构图直接推定。

## 四、三类边界

### A · 外部条件／观测限制

- 第三方设备的事件、SDK、资质和时效取决于具体型号、主体、接口与授权；当前未接入不代表永久不能接。
- 手机系统与推送通道影响后台提醒，不能承诺无条件必达。
- 区域存在、开关、开合、自报不能证明身份、情绪、吞服或安全。
- 已查文本模型／ASR／TTS 文档不自动提供完整全双工系统；也不能据此断言供应商永久不存在该能力。
- 系统不知道未接入的微信聊天或外部通话，不能编造家庭互动记录。

### B · 战略取舍

- 手机核心优先，可选硬件不作为交付门槛。
- 不建设完整社交平台或自建音视频通话；真实联系可用已有工具。
- 首版不默认覆盖代理同意、监护认定、专业医疗端和可靠急救。
- 普通话为首个验证范围，不提前承诺方言覆盖。
- 照片、复杂传感融合及更多平台按验证价值扩展。

### C · 系统责任与待解决问题

- 对话打断不自然、长语音漏记、Agent 漏处理或迟到结果覆盖更正。
- 记忆无来源、习惯被固化、跨用户混用、存储丢失或删除后复生。
- 未经授权生成家庭摘要、话题、原话或通知；撤销后仍可访问。
- 定时任务重复、错误取消整组计划、过期执行和通知状态误报。
- 子女端只剩任务，摘要去掉情感内容，自动代发假关心。

这些必须实现、测试或如实列为不足，不能用硬件接口受限解释。

## 五、商业与效果边界

谁付费、持续使用理由、可触达人群、BOM（如有）、云与语音成本、配置及售后负担仍需测算。不把老龄人口总量当市场规模，不把子女愧疚当支付意愿。

没有家庭试用数据，不宣称减少孤独、改善健康或提高亲情质量；也不因事项办结、阅读摘要或每日活跃就断言关系改善。指标见 [10](10-评测方案.md)。
