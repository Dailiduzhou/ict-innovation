## 二、系统架构

```
┌─────────────────────┐        ┌─────────────────────┐
│  老人端 (Android)    │        │  亲属端 (Android)    │
│  TS + React Native  │        │  TS + React Native  │
│  （同一 RN 工程，    │        │  + Kotlin 桌面小组件 │
│   角色判定切入口）   │        │                     │
└──────────┬──────────┘        └──────────┬──────────┘
           │   HTTPS / WebSocket          │
           │   HMS Push（通知消息+DeepLink）│
           └──────────────┬───────────────┘
                          ▼
        ┌──────────────────────────────────────┐
        │         API Gateway / 接入层           │
        │  鉴权 · 限流 · 幂等键 · 请求审计        │
        └──────────────┬───────────────────────┘
                       ▼
        ┌──────────────────────────────────────┐
        │         业务服务层（确定性）            │

        │  ItemService   事项状态机（唯一写入口） │
        │  PermService   权限校验（Agent 不可绕过）│
        │  NotifyService 提醒调度 + 频率限制      │
        │  MemoryService 长期记忆读写 + 闲时整理   │
        └───┬───────────────────────────────┬──┘
            ▼                               ▼
  ┌───────────────────┐        ┌────────────────────────────┐
  │   AI Agent 服务     │        │   数据源抽象层（09）         │
  │  ReAct 循环         │        │  ┌──────────────────────┐  │
  │  工具调用           │        │  │ VitalSource (端口)    │  │
  │  多假设推理         │        │  │  ├ MockVitalSource   │  │
  │  ★ 纯计算，无副作用  │        │  │  ├ ManualVitalSource │  │
  └───────────────────┘        │  │  └ HuaweiHealth(二期) │  │
                               │  ├ EnvironmentSource    │  │
                               │  │  ├ MockEnvironment   │  │
                               │  │  └ (真实:不可得占位)  │  │
                               │  └ TransportChannel     │  │
                               │     ├ Https / Mock      │  │
                               │     └ NearLink(三期预留) │  │
                               └──────────────┬─────────────┘
                                              ▼
        ┌──────────────────────────────────────────────────┐
        │                   华为云                          │
        │  ECS / CCE / FunctionGraph  （应用运行）          │
        │  RDS（MySQL/PG）  Redis  OBS  VPC/EIP/安全组      │
        │  IAM  CTS（审计）  SMN（通知，可选）              │
  │  ModelArts / 盘古大模型 / MaaS（LLM，工具调用）          │
        │  SIS（ASR/TTS，分段降级路径）                     │
        └──────────────────────────────────────────────────┘
```

**三条不可违反的架构原则：**

1. **Agent 无副作用权限**——Agent 只产出意图和文本，写入必须经业务服务层校验（`04` §1）
2. **`ItemService` 是事项状态的唯一写入口**——保证状态机与审计的一致性
3. **业务代码只依赖数据源端口，不依赖具体数据源**——`09` §二

## 四、关键技术选型

| 议题 | 选型 | 理由 |
|---|---|---|
| 双端形态 | **TypeScript + React Native**，**前期主要适配 Android**；Kotlin 仅做推送/桌面小组件/签名/Manifest；iOS 与 Web 列入二期 | 离线推送只能 Android 做（`11` §一）；TS 复用 Web 经验（`11` §4.1） |
| 推送 | **`PushChannel` 抽象 + 双通道**：主 HMS Push Kit（**通知消息 + Deep Link**，非数据消息），兜底 WebSocket | `11` §三；注意 Push Kit 属 **HMS Core，非华为云** |
| 推送桥接 | **`@hmscore/react-native-hms-push`**（HMS Core 团队官方维护，Apache-2.0，最新 6.13.0-302） | 不用从零写 Kotlin bridge；兼容性需先验（T-17） |
| 原生边界 | **Kotlin 不写业务逻辑**，只暴露窄接口（拿 token / 监听消息 / 读快照渲染小组件） | `11` §4.1 纪律 |
| 后端 | **Python**（✅ 已定） | KooCLI 与各 SDK 与语言无关；Qwen/豆包/华为云 MaaS **均有 Python 支持** |
| 实时语音 | **Qwen `qwen-audio-3.1-realtime-plus`**（备选豆包 Seeduplex）；华为云 SIS 作降级路径 | 华为云无端到端实时语音（`12` §五）；`smart_turn` 命中老人口语场景 |
| Agent 推理 | **华为云 MaaS（openPangu）**，与语音通道分离 | 体现赛题一“基于华为云产品”；MaaS 支持工具调用（`12` §5.3） |
| 联网搜索 | **自建 `web_search` 工具走 Function Calling** | 绕开 Qwen `enable_search` 与 FC 互斥的约束（`12` §四） |
| 语音协议 | WebSocket 优先；延迟不足时评估 **AOQ** / WebRTC | `12` §2.1 |
| 实时通信 | WebSocket | 事项状态双端同步 |
| 事项状态机 | 服务端唯一写入口 + 事件溯源 | 审计与可追踪性（`03` §5） |
| 记忆检索 | 阶段 1 用 RDS FTS + BM25 | `04` §3.4 |
| 幂等 | 客户端生成 `idempotency_key` | 防重复提交（`03` §3.1） |
| 权限模型 | RBAC + 资源级 ACL（`ItemGrant`） | 支持"只对某件事授权某人"（`03` §5） |
| 审计 | 只追加事件表 | 竞争力 C4 的证据 |
| 部署方式 | **KooCLI 脚本**（D-17 建议）；**工具不预置到仓库**，由 Agent 运行时获取（D-18） | 仓库保持干净；透明、可评审、可演示 |
| 客户端 | **TypeScript + React Native**（D-07b），**新架构 TurboModule + Codegen**（RN 0.88，Node ≥ 22） | 业务逻辑在 TS，Kotlin 只做 RN 覆盖不到的（`11` §4.1 / §4.7） |
| 原生模块 | **TurboModule + Codegen**（以 TS spec 为唯一接口真相源） | 旧架构已在 RN 0.82/0.83 移除（`11` §4.2.1）；**不用 Fabric** |
| **开发工具** | **CodeArts 代码智能体** | 赛题一强制 |
