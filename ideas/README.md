### v1 与 v2 的实质分歧（已决议，见 §0）

| 议题 | v1 | v2 | **v3 决定** |
|---|---|---|---|
| 产品中心 | 健康/环境**监测** | 家庭**协作事项**闭环 | **v2 的协作闭环** |
| 硬件 | 智能穿戴 + 智能家居 + 星闪是核心 | 首版不做硬件 | **抽象为端口 + mock，二期接真实设备** |
| 数据源 | 传感器自动采集 | 老人自述 + 授权分享 | **一期：自述/亲属/对话；二期：穿戴；家居仅留接口** |
| AI 角色 | 全局记忆 + 主动关怀 Agent | 需求结构化 + 工具调用 | **两者都保留**（见 `04`） |
