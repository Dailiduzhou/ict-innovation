# AgeGuard · 项目与技术文档

**当前主线：手机全双工语音＋并行 Agent Loop＋可靠个人长期记忆＋主动提醒＋经授权的家庭连接。硬件可选。**

先读 [product：用户、需求与叙事](../product/README.md)。本目录将产品主线落实为可验证的实现与交付要求，不反过来用板卡、框架或赛事包装定义用户价值。

## 三、本轮纠偏

- 从“必须交付语音盒＋药盒”改为手机独立成立，外围硬件只增加数据和体验。
- 从“先按键录音、全双工可后移”改为全双工与并行 Agent 是核心目标；分段语音仅开发／降级。
- 从“闲聊全部转事项”改为闲聊、记忆、分享、联系邀请、明确求助分别处理。
- 从“子女接单办结”改为了解近况、延续话题、真实回应，再处理明确请求。
- 从“可靠就是永久存储”改为理解、持久化、恢复、纠错、共享与删除分别负责。
- 从“某供应商产品不存在／学生一定拿不到权限”改为限定已查路径、主体、版本和验证状态。
