# AgeGuard · 项目文档

**面向老年人与异地家庭的 AI 关怀协作系统：一套完整后端＋语音盒＋药盒开合节点＋家庭应用。**

参赛：华为 ICT 创新赛赛题一｜大创创业训练。当前设计基线确认于 **2026-10-17**；已决策不等于已实现。

- 本轮跨端／药品规则以 `13` 和 `12` §四 D-25～D-39 为准；旧决定注明被替代，不伪装成仍全部有效。

- 当前仓库未提供应用、固件或端到端测试通过证据；原引用的部署 Skill 目录未找到，见 T-72。不得写“全部技术选型定稿”或“系统日志已证明”。

## 四、写作与证据约定

1. 区分**已决策／文档已核实／实测已通过**；未测指标写计划，不编造结果。
2. 外部 SDK 的语言、平台、数据和限制记录于 `08`；模型细节见 `11`，引用而不凭记忆扩展能力。
3. 实施未知项集中于 `12`；正文引用 T 项，不留模糊承诺。临时数字不冒充已确认阈值或医学参数。
4. 商用设备的数据通路受限，不等于自制节点不可行；传感器记录真实，不等于服药事实已核验。
5. 维护药品与提醒是经授权的辅助记录，不赋予家属或 AI 制定治疗方案的能力。
6. 已知缺陷须解决或如实登记；当前主体／配置的客观限制须说明范围，不能泛化成永久不可能。
7. 2026-12-01 是内部上云目标；官方阶段和材料截止以组委会通知为准。
