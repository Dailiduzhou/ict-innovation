## 三、写作约定

1. **外部能力事实只写在 `08`**，其他文件引用它，不重复解释
2. **模型/语音事实只写在 `11`**
3. **待验证项集中在 `12` §二**，风险在 `12` §三，决策日志在 `12` §四；正文不出现"待确认"
4. **决策已定即直述**，不复述"已决议/待拍板"；历史记录压缩在 `12` §四
5. 区分**客观条件限制**（换更强的团队也做不到）与**系统缺陷**（我们的活没干好）——见 `12` §一
