# 07 · 数据源、可选设备与 Mock

> 主要来源是手机对话与用户操作；硬件只增加情境。无设备不阻塞产品，未接入或模拟不冒充真实能力。产品形态见 [13](13-产品形态与可选硬件.md)。

## 一、核心真实数据链

手机真实音频／转写与轮次 → Agent 处理事件 → 记忆和提醒的受控持久化 → 授权家庭内容与真实留言。

文字、录屏和合成会话可用于开发、回归或显式降级，但不能替代核心全双工与跨会话存储证据。核心验收不要求真实药盒、语音盒或商用手表。

## 二、来源分类

| 来源 | 用途 | 必须保留的区别 |
|---|---|---|
| 老人对话与自述 | 生活背景、偏好、候选习惯、安排与反馈 | 转写修订、自述与事实核验不同 |
| 用户界面操作／语音确认 | 保存、变更、发送与撤销意愿 | 对应认证主体、动作、对象与版本 |
| 子女真实留言／反馈 | 双向近况、联系或具体请求处理 | 真实发送者、AI 草稿、观察和转述分开 |
| 原始来源片段 | 记忆追溯、核对与获准原话 | 允许保留不等于允许家庭播放 |
| AI 摘要／记忆／话题 | 派生候选和辅助理解 | 不是独立事实，不因摘要生成而产生访问权 |
| 有来源的用药安排 | 经核对的提醒依据 | 通用说明、个体安排、家属备注分开 |
| 存在传感器（可选） | 指定区域存在／活动 | 不保证身份、清醒、睡眠或安全 |
| 智能开关（可选） | 具体设备状态和事件 | 不证明本人做完某件事 |
| 药盒／语音盒（可选） | 容器动作／额外交互入口 | 开合不证明吞服，播放不证明听懂 |
| 穿戴／其他家居（可选） | 实际授权和可读指标／事件 | 逐型号、主体、SDK 与同步时效验证 |
| 合成／Mock／回放 | 开发、异常、回归与显式演示 | 不混入真实家庭、实测设备或效果统计 |

## 三、记忆与共享不是同一张来源表

记忆保留来源与适用时间，分享内容保留其依赖的记忆／来源版本、允许接收人和授权版本。原文更新、拒绝保存、更正、删除或撤销共享时，派生摘要、原话、话题、索引和发送任务都要检查影响。

AI 不向子女暴露未授权原文，再用“只供总结”当理由。子女端查询也不能拿全部私人记忆作模型上下文。缓存和备份恢复需尊重删除与撤销标记。

## 四、适配与能力声明

逻辑适配至少描述：

- 真实／模拟／回放，具体来源与采集主体。
- 平台、设备／固件／SDK 版本，实际字段与单位。
- 身份或绑定依据、授权范围、用途和可撤销方式。
- 发生时间、接收时间、时钟质量、同步延迟与缺失。
- 未接入、权限不足、离线、版本不支持等不可用原因。

对话来源还应带会话、轮次、转写修订和处理标识，避免工具调用与转写事件两路重复入库。具体契约在 T-77／78 定案，不把端口名写成已有实现。

## 五、硬件事件的最小规则

来源认证 → 结构与能力校验 → 事件幂等持久化 → 质量／时效判断 → 获准情境辅助。

自制事件去抖、传输重传和真实多次动作分开；第三方按实际事件 ID／序列／回调语义验证。不因模型“看起来合理”补造未采集数据。

区域存在、开关、开合、自报等来源可以并存，冲突不静默覆盖；新到的旧事件不当作当前动作。设备离线不等于没人活动，不能推断漏服或危险。

## 六、Mock 与开源

| 项 | 要求 |
|---|---|
| 构造 | 合成场景、虚构人物与空盒脚本，不伪造真实医院／处方／家庭经历 |
| 标记 | UI、材料与配置能辨识来源，混合内容逐项标识 |
| 语音 | 模拟输出、预录回放、分段语音和真实全双工分别标明 |
| 时钟 | 加速、跳时、测试调度与真实等待分开，明确过期策略 |
| 统计 | 合成测试、真实家庭、设备仿真和真机分开报告 |
| 开源 | 默认只公开无隐私 fixture、标注与脚本；真实音频、聊天、处方和家庭轨迹不自动公开 |
| 生产 | 测试身份、Mock 数据与真实记录隔离，启用入口可审计，防误写真实用户 |

推荐演示说明：“当前用手机展示实际完成的语音、记忆与任务路径；测试时钟、模拟通知或可选设备回放会单独标注。未完成的部分不计入实测。”

## 七、不可用和不确定性的呈现

自述写“本人表示……”；亲属转述写明记录者；设备写具体观测与时间；AI 候选标待核对；模拟标合成／回放。不使用 E1、E2、E3 等递增数字制造真实性阶梯，也不累加来源生成服药核验。

来源未知就保留未知，删除未完成就报告实际状态。正确理解、可靠存储、允许共享和实际行为完成是不同维度。
