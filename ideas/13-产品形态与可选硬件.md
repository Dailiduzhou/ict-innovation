# 13 · 产品形态与可选硬件

> 本轮用户澄清替代旧“语音盒＋药盒必须进一期”的路线。产品与需求见 [product](../product/README.md)，验收主线见 [03](03-产品与MVP.md)。

## 一、手机是完整入口，不是盒子的配置工具

老人可以只用所支持的手机完成自然交流、个人记忆、生活提醒与家庭分享。子女端是家庭关系入口，不仅用于接收通知。

全双工语音与后台 Agent Loop 是核心目标；按键分段录音可以开发、测试或故障降级，但不能作为全双工已交付的证明。远场唤醒与全天监听不是这一目标的必要条件，用户应能清楚开启、结束和静音。

## 二、四层产品形态

| 层 | 职责 | 必须条件 |
|---|---|---|
| 老人手机 | 双向音频、自然打断、记忆与提醒管理、共享选择 | 核心 |
| 后端 | 并行 Agent、可靠存储、任务调度、授权与恢复 | 核心 |
| 家庭视图 | 近况与原话、联系前回顾、真实留言、明确求助 | 家庭模式核心；老人可不邀请亲属 |
| 硬件适配 | 提供额外情境或更方便的交互 | 可选，不阻塞无设备使用 |

客户端框架、具体平台与主推送需实测；不能把“手机可用”写成“全部手机和后台条件都支持”。

## 三、硬件应回答的一个问题

> 接入这个设备后，是否减少了用户输入、重复询问或不合时宜的打扰？没有它，核心产品仍然成立吗？

自建和第三方设备都可以研究，不预设全部统一系统、品牌或协议。已有库存可降低探索成本，但不等于采购理由，更不等于用户价值证据。

| 数据源 | 可提供的观测 | 不能据此声称 |
|---|---|---|
| 人体存在传感器 | 在指定区域检测到存在／活动，取决于型号 | 已确认某位老人、清醒／睡眠、情绪、危险 |
| 智能开关 | 状态变化、事件时间及可用设备信息 | 某人已完成家务、已起床或已就寝 |
| 药盒／容器节点 | 稳定开合、设备状态 | 哪种药被吞服、漏服或用药正确 |
| 可选语音盒 | 增加一种录音、播放和控制入口 | 是使用产品的前提，或天然比手机适老 |
| 可选穿戴测量 | 经过许可且实际可读的具体指标 | 任意手表可接、数据实时且保证安全 |

## 四、第三方与自建接入的不同工作

### 第三方

逐型号验证官方 API、本地协议或获许可网关，记录账号主体、用户授权、SDK 语言／平台、字段、采集与同步时间、限额、版本和停服风险。

生态宣传不等于应用可读取所有设备历史；用户同意也不自动替代厂商许可或 SDK 适配。没有合法可用通路时明确未接入，不绕过配对、加密或访问控制。

### 自建

验证板卡、驱动、真实固件系统、传感器安装、认证、事件协议、供电与恢复。MQTT／HTTPS 是候选传输，不是健康或行为语义。

IoTDA 可以是自建节点的接入候选，不强迫全部第三方设备绕行该平台。设备侧 C SDK 与后端应用侧 Python SDK 不混用；出处见 [08](08-外部依赖核查.md)。

## 五、无硬件优先的处理路径

```text
手机对话／用户操作 ───────────────→ 核心业务与 Agent
                                        ↑
可选设备 → 来源认证／能力适配 → 事件持久化／质量与时间校验
                                        ↓
                             允许的情境辅助与交互建议
```

传感器不直接写入“已完成家务”“本人已服药”等人物事实，不直接给子女广播。设备绑定、信息用途、共享范围与解绑可撤销；设备认证不等于本人身份。

## 六、事件可靠性与不确定性

- 发生时间与接收时间分开，未知时间保留未知，迟到事件不当成当前状态。
- 抖动、传输重试和真实多次动作分开处理，事件幂等。
- 原始观测与人员说明并存，冲突不静默覆盖。
- 离线表示数据不可用，不表示没有活动、发生危险或一切正常。
- 离线本地执行仅在专门实现、计划有效、时钟可信时启用；未实现不承诺。
- 如果设备支持提醒播放，接收、播放和本人理解分别记录；过期或旧版本不能恢复后重播。
- 保留期限按最小必要设定，不因可追溯就永久收集家庭轨迹。

## 七、设备验收独立于核心软件

| 编号 | 设备验证 | 通过条件 |
|---|---|---|
| H-01 | 无设备使用 | 核心对话、记忆、提醒、家庭连接不依赖设备 |
| H-02 | 字段与语义 | 实际观测与文档／展示一致，不夸大人物事实 |
| H-03 | 绑定与撤销 | 错误绑定、解绑后重放与越权访问被拒绝 |
| H-04 | 重复／乱序／抖动 | 不重复副作用，不丢真实动作 |
| H-05 | 离线／时钟错误 | 显示未知与质量，不伪造时间和安全结论 |
| H-06 | 设备下行（如采用） | 版本、过期、回执和恢复正确 |
| H-07 | 硬件增益对照 | 比较同一任务有／无设备的操作、打扰和误解 |
| H-08 | 证据与复现 | 具体型号、固件、权限、真实／模拟标识及复现步骤 |

这些是可选适配测试，不是核心必须采购的清单。药盒测试用空盒；不安排真实漏服或重复服药。旧 H-01～H-16 已由核心软件验收与此设备分支替代，不沿用旧编号语义。

## 八、取舍与责任

无设备、暂未取得某品牌接口是当前范围或外部条件，不是核心软件无法开始的理由。错误推断、越权共享、数据丢失和过期执行则是系统责任，不能归咎于硬件观测有限。
