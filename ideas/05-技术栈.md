# 05 · 技术栈与选型状态

> 产品依据见 [product](../product/README.md)。核心架构确定不等于供应商、框架和版本全部定稿；官方文档支持不等于账号和真机实测。

## 一、逻辑架构

```text
老人手机 ↔ HTTPS／实时音频通道 ↔ 后端会话与语音适配 ↔ 语音服务
                                         │
                         轮次事件／来源修订／输出协调
                                         │
                            并行 Agent 与受控工具网关
                                         │
                     身份／授权／记忆／计划／共享／消息／请求
                          ├ RDS：事实、修订、持久化任务
                          ├ Redis：缓存、会话、频控等辅助
                          └ 调度／发送工作进程 → 手机提醒与家庭通知
                                         ↑
家庭 Web／手机视图 ──鉴权请求──────────────┘

可选自建／第三方传感器 → 适配、认证、能力和时间质量 → 情境事件
```

音频双向通道、后台 Agent 与业务 API 是不同职责。是否使用 WebSocket、WebRTC 或供应商协议，需验证手机、后端代理和网络；不能用一张箭头图证明全双工。

## 二、方向与未决项

| 层 | 当前方向 | 必须验证 |
|---|---|---|
| 老人入口 | 手机主动开启的自然语音与管理界面 | 录放音并发、回声、打断、权限、后台与弱网 |
| 家庭入口 | 近况／原话、联系前回顾、真实留言、明确求助 | 无待办价值、隐私、负担与双向使用 |
| 客户端 | Android 优先验证；Web 支持原型／在线 Demo | 框架、系统版本与覆盖清单；RN 是候选，不统一锁旧版本 |
| 后端 | Python 方向 | 异步音频／事件、取消和任务恢复，框架待实测 |
| 语音 | Qwen Realtime 为优先 PoC 候选 | 官方 Python WebSocket 示例可参考；实际接口与账号测试见 `08` |
| Agent 推理 | 华为云 MaaS 候选 | 工具与 schema、延迟、具体模型能力与计费 |
| 持久化 | RDS 保存关键记录与唯一任务账本 | 引擎、事务、迁移、备份、恢复、删除 |
| 辅助服务 | Redis 用于会话、缓存、频控或队列辅助 | 不作唯一记忆、调度或发送账本 |
| 检索 | 结构化与适用全文检索优先 | 按引擎验证排序，向量检索按效果扩展 |
| 调度／通知 | 持久化计划与发送任务，客户端通道实测 | 时区、版本、恢复、手机后台、回执与未知 |
| 搜索 | 可选公共实时信息查询 | 权限、费用、出站隐私与结果质量；不阻塞核心 |
| 硬件 | 自建或第三方存在／开关等可选数据 | 型号、SDK 语言、字段、权限、时效和独立增益 |

Qwen 的协议支持不能直接外推到所选手机框架；MaaS 的 HTTP 示例不等于存在某语言原生 SDK。采用前按 [08](08-外部依赖核查.md) 与 [12](12-风险与待验证.md) 补证。

## 三、华为技术各自负责什么

| 能力 | 实际职责 | 不应声称 |
|---|---|---|
| CodeArts | 开发阶段需求理解、编码、构建、修复与上线 | 等同产品运行时 Agent |
| 已有智能体／Skills | 创建、关联资源和部署；按需补项目内容 | 写两个自定义 Skill 就完成要求 |
| RDS／Redis | 业务持久化和辅助能力 | 实例能查询就证明恢复可靠 |
| ECS／网络 | 在线服务、音频连接、后台工作进程 | 只打开登录页就是端到端通过 |
| MaaS（如采用） | 有界 Agent 推理和候选生成 | 模型原生决定权限或保证语义正确 |
| IoTDA（可选） | 适用自建节点的设备接入 | 是全部第三方硬件的必经通路 |
| OpenHarmony（可选） | 适合板型时的真实固件实现 | 采用 ESP-IDF 也称 OpenHarmony |
| HMS Push（候选） | 特定客户端消息通道 | 是华为云通用推送或无条件全机型必达 |

赛事事实见 [00](00-赛事要求.md)。不因覆盖更多产品而宣称必然加分或晋级。

## 四、安全、费用与实现状态

- 长期模型 Key、云 AK/SK 不进手机、设备、仓库和公开日志。临时凭证仅在供应商实际支持并完成限权验证后使用。
- TLS 校验必须开启，官方示例中的不安全调试配置不能照搬。
- 音频、转写、记忆与家庭投影的数据流向和期限分开说明，模型服务出站仅带必要内容。
- 分段语音、Mock 和录屏可以开发／降级，但不能抵扣真实核心验收。
- 外部语音费用与华为云代金券分别核实，不预设跨厂商覆盖。
- 当前仓库仅设计文档，没有应用、固件或端到端通过证据；部署 Skill 的文件缺口见 T-72。
