## 一、系统架构

```
┌─────────────────────┐        ┌─────────────────────┐
│  老人端 (Android)    │        │  亲属端 (Android)    │
│  TS + React Native  │        │  TS + React Native  │
│  （同一 RN 工程，    │        │  + Kotlin 桌面小组件 │
│   角色判定切入口）   │        │                     │
└──────────┬──────────┘        └──────────┬──────────┘
           │   HTTPS / WebSocket          │
           │   HMS Push（华为设备）        │
           │   自建长连接（其他设备）       │
           └──────────────┬───────────────┘
                          ▼
        ┌──────────────────────────────────────┐
        │         API Gateway / 接入层           │

                       ▼
        ┌──────────────────────────────────────┐
        │         业务服务层（Python，确定性）    │
        │  AuthService   账号与绑定关系          │
        │  ItemService   事项状态机（唯一写入口） │
        │  PermService   权限校验（Agent 不可绕过）│
        │  NotifyService 提醒调度 + 频率限制      │
        │  MemoryService 长期记忆读写 + 闲时整理   │
        └───┬───────────────────────────────┬──┘
            ▼                               ▼
  ┌───────────────────┐        ┌────────────────────────────┐
  │  语音层             │        │   数据源抽象层（07）         │
  │  Qwen Realtime     │        │  VitalSource（端口）        │
  │  全双工 + FC        │        │   ├ Mock / Manual / 亲属     │
  │        │           │        │   └ HuaweiHealth（二期）     │
  │        │request_task│       │  EnvironmentSource          │
  └────────┼───────────┘        │   ├ Mock / 空占位           │
           ▼                    │  TransportChannel           │
  ┌───────────────────┐        │   └ Https / NearLink（预留） │
  │  事务层（Agent）    │        └──────────────┬─────────────┘
  │  华为云 MaaS        │                       │
  │  ReAct + 工具调用   │                       │
  │  ★ 纯计算，无副作用 │                       │
  └───────────────────┘                       │
                                              ▼
        ┌──────────────────────────────────────────────────┐
        │                   华为云                          │
        │  ECS（应用运行）  RDS  Redis  VPC/EIP/安全组      │
        │  MaaS（Agent 推理）  SIS（语音降级路径）          │
        │  OBS（审计归档）  IAM  CTS（云审计）              │
        └──────────────────────────────────────────────────┘
```

**三条不可违反的架构原则：**

1. **Agent 无副作用权限**——只产出意图和文本，写入必须经业务服务层校验（`04` §1.4）
2. **`ItemService` 是事项状态的唯一写入口**——保证状态机与审计一致性
3. **业务代码只依赖端口，不依赖具体实现**——数据源、推送、语音、LLM 四处都做抽象

## 三、关键选型

| 议题 | 选型 | 理由 |
|---|---|---|
| 客户端 | **TypeScript + React Native**（Android 优先） | 离线推送只能 Android 做（`06` §一）；TS 复用 Web 经验 |
| RN 架构 | **新架构 TurboModule + Codegen**，锁定 **RN 0.88** / Node ≥ 22 | 0.82+ 已无旧架构（`06` §4.2.1） |
| 原生边界 | Kotlin 仅做推送 / 桌面小组件 / 签名 / Manifest；**不写业务逻辑** | `06` §4.1 |
| 后端 | **Python** | 各 SDK 均有 Python 支持；与赛题无冲突 |
| 语音层 | **Qwen `qwen-audio-3.1-realtime-plus`** | `smart_turn` 命中老人口语场景；`11` §三 |
| 事务层 | **华为云 MaaS（openPangu）**，实时用 `-flash` 关思考 | 赛题契合 + 工具调用 + 代金券可用；`11` §三 |
| 联网搜索 | **自建 `web_search` 工具走 Function Calling**，底层用**博查 `ai-search`** | 绕开 `enable_search` 与 FC 互斥；博查免费 1000 次且有天气/医疗模态卡；`11` §四 |
| 实时通信 | WebSocket | 事项状态双端同步 |
| 事项状态机 | 服务端唯一写入口 + 事件溯源 | 审计与可追踪性（`03` §五） |
| 记忆检索 | 阶段 1 用 RDS FTS + BM25 | `04` §6.4 |
| 幂等 | 客户端生成 `idempotency_key` | 防重复提交 |
| 权限模型 | RBAC + 资源级 ACL（`ItemGrant`） | 支持"只对某件事授权某人"（`03` §五） |
| 审计 | 只追加事件表 | 竞争力 C4 的证据 |
| 部署方式 | **KooCLI 脚本**；工具不预置到仓库 | `09` §三 |
| 区域 | 应用 `cn-north-4`；**MaaS 仅"西南-贵阳一"**（跨区，需实测延迟） | `11` §五 |
