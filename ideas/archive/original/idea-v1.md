# AgeGuard

## 项目介绍

结合智能硬件（智能穿戴，智慧家居等），了解关怀高龄/空巢老人的App/小程序。

## 产品对象

1. 老人
2. 老人子女和亲戚
3. 医疗人员

## 对不同人提供的信息

1. 对老人

- 近期身体指标信息
- 天气信息，提醒增减衣物，带口罩
- 伴随起床/吃药闹钟的提醒语
- 解答生活小问题(食物搭配等)
- 使用定时任务或trigger，对老人进行一定程度的情感关怀
- 记录偶发身体不同部位的病痛

2. 对老人子女和亲戚

- 老人近期身体指标信息
- 老人最近在产品提醒下按时吃药情况，病痛情况
- 老人表达的想念信息，进行提醒

3. 对医疗人员

- 过往用药情况
- 全局记忆中的病史

## 数据来源和采集方式

IoT

1. 老人自述，问卷填写情况
2. 智能穿戴提供的心率，血压，HRV等信息。
3. 智能家居的信息（例如，卧室灯的开关时段，不同区域的人在传感器的激活情况，门锁的解锁锁上情况）
4. 老人和App的AI闲聊内容，进行全局记忆的整理

连接方式可以使用华为最新的星闪。

### 老人自述，闲聊采集

接入AI，进行语音聊天。
留存聊天信息，日志。

语音转文字，支持方言之类的。

### 智能穿戴 SDK

使用华为智能穿戴SDK

保留接入其他家服务的扩展性，总结高级的抽象。

### 智能家居信息

了解SDK

## AI的参与

### 闲聊

语音聊天

### 全局记忆

前期使用纯文本 + FTS + BM25
后期可以扩展RAG

实现细节上，可以闲时进行记忆内容的整理，保持记忆内容一定时间更改次数内的审计记录。要求全局记忆的新增和修改不导致过分的膨胀。

### Agent

统一的ReAct循环，进行全局记忆的整理
进行天气变化提醒，增减衣物，佩戴口罩
不定期的关怀信息的发送。
比较后期的实现。除了Markdown之外，进行docx, pdf等产物(articraft)的产出。
