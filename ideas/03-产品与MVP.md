# 03 · 产品与 MVP
!!!!要点在于我们的产品能够通过记忆和传感器信息，主动向老人进行问候、寒暄。

> 当前方向见 [product](../product/README.md)。本文是计划与验收定义，不是已上线功能清单。手机独立成立；全双工与并行 Agent 是核心目标，硬件可选。

## 一、首版产品组成

| 组成 | 核心交付 | 不等同于 |
|---|---|---|
| 老人手机入口 | 登录、主动开启／结束语音、打断与改口、提醒与记忆管理 | 专用语音盒、持续后台监听 |
| 后端语音＋Agent | 并行交流与后台整理、检索、受控工具执行 | 一个任意写库或自行共享的模型循环 |
| 个人长期记忆 | 有来源、时间、确认与版本，可靠持久化、检索、纠错、删除 | 无限保存聊天、家庭共用档案 |
| 定时任务 | 生活提醒创建、查询、修改、取消与反馈 | 模型临时想起、只在当前会话里等待 |
| 家庭视图 | 少量近况＋原话、联系前回顾、真实留言、明确请求 | 只有待接单列表或每日风险看板 |
| 通知与恢复 | 手机提醒、家庭消息、持久化发送记录与有限重试 | API 成功即本人知晓 |
| 可选适配 | 自建或第三方存在／开关等数据源 | 首版必需语音盒＋药盒 |

手机支持范围必须发布实际验证的平台、系统、权限与后台条件。Web 可用于原型和在线演示；网页能录音不等于手机后台提醒已通过。

## 二、三种内容，三条流程

### 2.1 私人交流与记忆

```text
语音交流 → 带来源的记忆候选 → 校验／必要澄清 → 个人记忆持久化
                                         ↓
                               下次检索、查看、纠错、删除
```

纯闲聊可以不生成记忆或动作。用户拒绝保存的内容不进入长期记忆；拒绝分享与删除是不同操作。

### 2.2 生活提醒

```text
交流中的安排 → 提醒建议 → 本人确认／有效预授权 → 计划版本＋持久化调度
                                                        ↓
                                       到时执行 → 通知状态／本人反馈
```

计划、每次执行与本次反馈分开。完成一次不取消未来全部安排，修改计划撤销旧未来执行；过期和断线恢复不能重复执行。

### 2.3 家庭连接

```text
获准分享的内容 → 授权投影
                ├ 近况／原话：可阅读，不要求办结
                ├ 联系线索／邀请：帮助延续交流，可回应或协商
                └ 明确求助：接手、处理、反馈
子女主动留言 → 本人发送确认 → 按老人接收设置转达
```

子女的真实留言与 AI 草稿明确区分，不自动代发。不创建“孝心评分”，不把摘要阅读与亲情质量混为一谈。

## 三、权限与确认

| 操作 | 老人／内容主体 | 获授权亲属 | Agent |
|---|---|---|---|
| 使用私人记忆 | 查看、更正、删除与限制保留 | 不默认可见 | 在允许范围内检索、提出候选 |
| 创建普通生活提醒 | 确认或明确开启规则 | 经相应授权协助 | 提议或按有效规则提交 |
| 共享近况、原话、话题 | 决定对象、类别与范围 | 仅看授权投影 | 不自行扩权 |
| 创建具体请求 | 确认接收人与内容 | 接手、协商、反馈 | 提议并经业务服务执行 |
| 发送子女留言 | 接收方式由老人控制 | 本人确认发送 | 不伪造／冒充 |
| 用药安排 | 基于有来源、已核对的现有安排 | 另授录入／维护权限 | 不开方、不推导剂量、不自行启用 |
| 绑定传感器 | 明确关联人、区域、用途和共享 | 仅获准设备管理 | 不把设备身份当作本人 |

确认可以来自经认证会话中的明确语音意愿或界面动作，须关联当前对象、动作和版本；不强制实体确认键，也不能只凭模型的一句“用户同意”执行。

## 五、核心验收

- 手机真实双向音频、播放中打断、长停顿／附和、改口和并行 Agent；分段录音不抵扣全双工。
- 跨会话记忆召回、来源保真、纠错、跨用户隔离、保存失败提示、备份恢复与删除。
- 自然交流创建提醒，计划查询与取消，进程重启／重试／时区／过期不产生错误副作用。
- 子女端没有待办仍能了解授权近况、回顾话题、发送真实回应；明确请求独立跟进。
- 拒绝共享、撤销、敏感原话、摘要和话题旁路泄露测试。
- 实测手机通知及失败／未知状态，真实联系与系统内反馈分开。
- 云端可运行、CodeArts／Skills 开发部署证据、另一成员复现。
- 用户价值按 [10](10-评测方案.md) 对照，不以架构完成或办结率代替。
