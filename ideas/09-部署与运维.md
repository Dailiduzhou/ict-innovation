# 09 · 部署、可靠存储与运维

> 赛题要求及既有核查记录见 [00](00-赛事要求.md)。本文件是实施与验收设计，不是已创建资源、已安装工具或已复现脚本。

## 一、部署目标

华为云上可运行的手机语音入口与业务后端，支持长连接、并行 Agent、个人记忆、定时任务、家庭内容和通知。公网能打开页面只是基本检查，不证明手机双工或后台任务可靠。

2026-12-01 是既有内部首次上云目标，不冒充官网独立截止。当前部署 Skill `.agents/skills/huaweicloud-koocli-deploy/` 未在检出中找到，不能列为交付。

## 二、逻辑部署单元

| 单元 | 责任 | 要验证什么 |
|---|---|---|
| HTTPS／实时连接入口 | 鉴权、音频会话、连接路由 | TLS、代理升级／超时、弱网、断开与并发 |
| 语音与会话服务 | 双向音频、轮次、打断与输出协调 | 限流、取消、重连、过期结果和资源释放 |
| Agent 工作进程 | 消费持久化处理事件、有界工具编排 | 崩溃恢复、重复投递、版本、费用与积压 |
| 业务 API | 记忆、计划、共享、留言、明确请求 | 身份、资源授权、事务与并发 |
| RDS | 关键记录、来源修订、唯一任务与 Outbox | 迁移、约束、备份、恢复、删除与权限 |
| Redis | 会话、缓存、频控或队列辅助 | 丢失与重启时不损坏唯一业务事实 |
| 调度与发送进程 | 定时实例、通知与有限重试 | 锁／租约、幂等、过期、取消和未知状态 |
| 来源存储（按需） | 获准音频／原话、转写等 | 最小化、访问控制、期限、删除和恢复 |
| 可选设备适配 | 自建／第三方事件入口 | 独立认证、能力、时间质量，不阻塞主线 |

是否拆成多个部署进程由容量和可维护性决定，不为架构图强制微服务。存储、队列、框架、区域与最小规格在 T-69／70／71／74／83 定案。

## 三、可靠存储不是只买数据库

1. 记忆、计划和消息持久化成功后才对用户确认相应成功。
2. 业务变更与必要处理／发送任务共同持久化，避免提交后崩溃导致永久遗漏。
3. 重试、重启和多工作进程不重复副作用；记录处理状态与可恢复错误。
4. 修改、取消或撤销使旧版本任务失效，恢复后不执行过期提醒。
5. 存储、索引、缓存、共享投影与备份有删除策略，恢复流程应用删除与撤销记录。
6. 原文、音频和审计各有期限，不以“可靠”承诺永久保存所有内容。
7. 恢复演练记录可恢复点、耗时、丢失／重复范围与人工步骤；没有演练不宣称零丢失。

## 四、资源与网络

应用、数据服务原则上使用限权内网访问；公网只开放必要入口，数据库与缓存不全网暴露。端口按实际引擎配置，不把 MySQL／PostgreSQL 同时作为已定选型。

语音服务与模型区域可能不同，带宽、出站流量、代理往返和跨区延迟均需测量。语音代理是否支持实际协议，不能由普通 HTTP 健康检查推断。

可选 IoTDA／设备资源独立开通和预算；不把全部第三方设备强制纳入自建节点拓扑。

## 五、开发和部署工具

实际使用 CodeArts 与适用的已有智能体／Skills，保存创建、关联、构建、修复和部署证据。KooCLI 是候选工程工具，不是独立必选指标；原缺失 Skill 须恢复或重建并实测。

如采用 KooCLI：

- 按 [官方文档](https://support.huaweicloud.com/usermanual-hcli/hcli_05_01.html) 核实安装、版本、服务代号、参数、dry-run 和异步等待。
- 先做只读发现；创建／计费与删除动作显式确认，不凭记忆写 operation。
- 先核实沙箱策略，不把“关闭保护”作为默认解法；优先限权授权或受控终端。
- 工具、凭据和第三方安装包不提交；脚本记录前提、失败恢复、重复运行与清理。
- 模板、命令片段和列出文件名不等于仓库实际存在脚本。

[官方 devkit](https://github.com/huaweicloud/huaweicloud-devkit) 与 [Skills](https://github.com/huaweicloud/huaweicloud-skills) 可作线索，实际覆盖与许可需读取版本说明。

## 六、凭证和日志

- 云凭据、模型 Key、推送密钥不进客户端、设备、仓库、提示词或公开日志。
- 开发／CI／运行时分角色限权，优先委托或受控 secret 注入；云委托不意味着第三方模型 Key 自动消失。
- TLS 校验保持开启；官方示例中的不安全调试参数不能照搬。
- 调试输出可能含鉴权、原文、音频、私密查询，不因排错就默认全量记录。
- 删除权限按实际清理角色限权并确认，不用“完全不授删除”与清理脚本互相矛盾。
- 凭证泄露需撤销轮换并检查历史，添加 gitignore 不能消除已提交秘密。

## 七、成本与服务连续性

分别核算语音输入／输出、Agent、记忆整理、存储、备份、网络、数据库、通知及可选硬件。外部厂商费用不预设由华为云代金券覆盖；云内是否适用也以实际套餐确认。

按需开启语音会话、空闲释放连接，限制 Agent 步数／并发，设置预算告警。不能为了省钱默默截掉长语音或将“分段降级”仍宣传为全双工。

缓存命中、模型单价和“使用免费额度”都不等于真实家庭成本。固定五分钟付费上限尚未定案，不把它写成现行规则。

## 八、完整复现验收

另一成员在干净环境完成配置、迁移、构建／部署与访问，运行：

1. 手机真实全双工与并行处理。
2. 跨会话记忆及写入／检索失败处理。
3. 调度重启、提交后崩溃、重复任务、取消与过期。
4. 家庭授权投影、真实留言及明确请求。
5. 原话链接、缓存、索引与备份恢复后的撤销／删除。
6. 手机通知平台矩阵和未回执的未知状态。
7. 费用检查、限权资源清理和恢复步骤。

实时、回放、模拟分别标注；只查实例、只看登录页或只在作者电脑上跑通不计完整通过。对应 T-70／72／74／75／83。
