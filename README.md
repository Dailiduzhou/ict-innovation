## ⚠️ 六个最容易翻车的点

1. **赛题一红线**：必须用 **CodeArts** 开发 + 关联 **RDS/Redis** + **部署在华为云可在线运行**。
   "未采用赛题要求的华为技术的队伍不符合参赛资格。"
2. **Mock 必须自证**：赛题规定"代码无法复现 PPT 效果将取消资格"。
   演示用 mock 可以，但 **UI 徽标 + PPT 脚注 + 类名 `Mock` 前缀**必须齐全。→ `ideas/07` §一
3. **荣誉不是华为**：荣耀需独立 HONOR Push；小米/荣耀还有企业账户与上架门槛。
   HMS Push 只覆盖华为设备。→ `ideas/06` §二
4. **华为云没有端到端实时语音**：MaaS 是文本 LLM，SIS 是 ASR/TTS 分段。
   语音通道用第三方（客观限制），但**要在材料里主动说明理由**。→ `ideas/11` §二
5. **语音层与事务层别混着写**：两层通过 `request_task` 工具桥连接，
   **事务层不直接说话、语音层不直接写数据**。→ `ideas/04` §1.3
6. **API Key 不进客户端/仓库**：赛题一要求开源，一旦写进代码就会公开。
   → `ideas/09` §六

## 📐 写作规范（遵守 `AGENTS.md`）

1. **区分「客观条件限制」与「系统缺陷」**
   判定法：换一支更强的团队能不能做到？**能 → 缺陷；不能 → 限制**。→ `ideas/12` §一
2. **核实外部 SDK**：适配的语言、能提供的数据和功能，逐条核到官方文档，附来源。
   → `ideas/08`（外部能力事实的唯一来源）
3. **不编造数据**：未测量的指标一律写"计划评测指标"。→ `ideas/10` §五
4. **事实只写一次**：其余处引用编号，不重复解释。→ `ideas/README.md` §三
