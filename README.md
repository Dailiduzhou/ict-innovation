# AgeGuard · ICT 创新赛＋大创（创业训练）

> **面向老人的语音生活助理：自然交流、个人长期记忆、主动提醒，以及经授权的家庭连接。**

老人通过手机与助理自然交流；后端全双工语音与 Agent Loop 并行，整理允许保留的重要信息，把确认过的安排变成后续提醒。子女端帮助了解近况、回顾可以接着聊的话题、表达真实回应，明确求助才进入事项跟进。

**手机即可使用；语音盒、药盒不是必备项。** 自建或其他品牌的人体存在传感器、智能开关等只作为可选数据源，具体能力逐项验证。

## 产品的三条价值线

1. **老人自己有用**：愿意聊天、少填表，跨次交流不用重复交代，确认过的安排能被记住和提醒。
2. **家人更容易连接**：减少整理碎片信息的负担，保留父母愿意分享的声音与生活，帮助下一次真实交流。
3. **需要时才办事**：明确求助有接手与反馈，但不把闲聊、联系邀请和亲情都变成工单。

“部分老人连续分享长语音”是讨论中的观察，仍需访谈，不泛化所有老人。目标不是减少真实交流，也不是用 AI 替子女尽孝。

## 当前状态

- **已明确的方向**：手机基础入口、全双工与并行 Agent、个人长期记忆和受控提醒、子女关系入口、硬件可选。
- **待验证的设计**：子女端“最近的生活／下次聊什么／需要你参与”、原话片段、双向留言，以及各项交互与价值假设。
- **尚无完成证据**：当前仓库没有应用、固件或端到端测试通过材料。架构图、SDK 文档与产品决定不等于实现完成。
- **关键路径**：手机自然对话＋并行处理 → 有来源的记忆与恢复 → 提醒与权限 → 子女端近况／回顾／回应／明确求助 → 家庭对照评测与云端复现。可选硬件独立验证。

- 遵守 [AGENTS.md](AGENTS.md)：区分外部条件、战略取舍与系统责任。

- 不诊断、不自行改药，不将存在／开关／开合、自报或通知受理当作安全或完成证明。
- 实时、回放、合成数据分别标识；真实聊天、语音、处方、家庭轨迹与密钥不默认开源。
