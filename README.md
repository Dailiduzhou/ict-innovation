## ⚠️ 五个最容易翻车的点

1. **赛题一红线**：必须用 **CodeArts 代码智能体**开发 + 关联 **RDS/Redis** + **部署到华为云可在线运行**。
   "未采用赛题要求的华为技术的队伍不符合参赛资格。"
2. **Mock 必须自证**：赛题规定"代码无法复现 PPT 效果将取消资格"。
   演示用 mock 可以，但 **UI 要有徽标、PPT 要有脚注、类名要有 `Mock` 前缀**。
   → [`ideas/09`](ideas/09-数据源抽象与Mock策略.md) §一
3. **推送别说过头**：❗ **荣耀已经不是华为**，需单独接 HONOR Push；小米/荣耀还有企业账户与上架门槛。
   华为 Push Kit 只覆盖华为设备。→ [`ideas/11`](ideas/11-客户端与推送方案.md) §2.3 / §2.4

4. **华为云没有端到端实时语音**：MaaS 是文本 LLM，SIS 是 ASR/TTS 分段。
   本项目语音通道用第三方（客观条件限制），但**要在材料里主动说明理由**。
   另外：Qwen 的**联网搜索与工具调用互斥**，需自建搜索工具绕开。
   → [`ideas/12`](ideas/12-实时语音与模型选型.md) §四 / §五
5. **语音层与 Agent 层别混着写**：两层通过 `request_task` 工具桥连接，
   **事务层不直接对老人说话、对话层不直接写数据**。
   → [`ideas/14`](ideas/14-语音层与Agent层分工.md) §五

## 📐 写作规范（本仓库遵守 `AGENTS.md`）

1. **区分「客观条件限制」与「系统缺陷」**
   判定法：换一支更强的团队能不能做到？**能 → 缺陷；不能 → 限制**。
   → [`ideas/08`](ideas/08-风险-取舍-待决策.md) §一
2. **核实外部 SDK**：适配的语言、能提供的数据和功能，逐条核到官方文档，附来源。
   → [`ideas/06`](ideas/06-外部依赖核查报告.md)
3. **不编造数据**：未测量的指标一律写"计划评测指标"，不写百分比。
   → [`ideas/07`](ideas/07-评测与验证方案.md) §五
4. **不声称未实现的能力**：分层陈述 + 禁用表述清单。
   → [`ideas/09`](ideas/09-数据源抽象与Mock策略.md) §6.2
