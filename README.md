# AgeGuard · ICT 创新赛（赛题一）＋大创（创业训练）

> 面向老年人与异地家庭的 **AI 关怀协作系统**。
> 第十一届华为 ICT 大赛创新赛赛题一「基于华为云产品打造 AI 创新应用」。

## 当前产品路线

**一套完整后端＋自制语音盒＋药盒开合节点＋家庭应用。**

- 老人通过实体按键说话、听草稿、确认或取消，查看事项进度；第一版不要求触摸屏、远场唤醒或全双工。
- 自制药盒节点提供真实开合事件。**开盖≠服药，播放≠知晓，无反馈≠漏服**。
- 亲属通过 Web／移动接收端查看授权事项、接手反馈；获授权后协助维护有来源和版本的药品／提醒。
- 完整鉴权、人的身份、设备身份、资源授权、业务状态机、持久化、审计与恢复不删减。
- Webhook 只补充通知，不替代站内待办、移动接收端及通知状态记录。

文字／Web 可以先验证业务闭环，但不能抵扣一期硬件交付。模块负责人同时负责实现、测试、文档和联调。

4. 模拟、回放和真实采集逐项标识；开源不包含真实处方、私密聊天或密钥。
